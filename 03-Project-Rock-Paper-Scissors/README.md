# Rock Paper Scissors

A simple Rock Paper Scissors game built with JavaScript as part of [The Odin Project](https://www.theodinproject.com/).

## About

This is a console-based Rock Paper Scissors game where the player plays against the computer for 5 rounds.

## Features

- Computer randomly chooses rock, paper, or scissors
- Player chooses using a prompt
- Keeps track of the player and computer scores
- Plays 5 rounds
- Announces the final winner
